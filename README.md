# WuxAuto

Downloads only - the source is not published here.

Get **WuxAuto-win-x64.zip** from the [latest release](https://github.com/atherosxd/WuxAuto/releases/latest),
unzip it into a folder of its own and run `WuxAuto.exe` (no .NET install needed). The first start asks
for a key from the owner. Every start installs a newer release by itself, so there is only ever one
version to download.
